# Security and data handling

Please do not submit real personal contact data, credentials, or confidential company information in public issues.

OpsPilot stores CRM records locally in `.opspilot/opspilot.db`. This path is excluded from version control. The demonstration dataset contains synthetic identities and reserved `.example` domains.

For a security concern, contact the repository owner privately through the email address listed on their GitHub profile rather than opening a public issue.
