# Contributing

Thanks for your interest in OpsPilot.

1. Open an issue describing the user problem and proposed behavior.
2. Create a focused branch from `main`.
3. Keep scoring decisions explainable and outreach human-reviewed.
4. Do not commit API keys, CRM databases, or real personal contact data.
5. Explain product tradeoffs in the pull request description.

Feature ideas that improve provenance, evaluation, or workflow clarity are especially welcome.
